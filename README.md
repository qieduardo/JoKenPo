# ✊🖐✌️ JoKenPo

Um jogo clássico de **Pedra, Papel e Tesoura** interativo. O projeto foi desenvolvido com o objetivo de praticar lógica de programação, estruturas condicionais e manipulação de eventos.

## 🚀 Funcionalidades
* Escolha entre Pedra, Papel ou Tesoura.
* Oponente (computador) faz uma escolha aleatória.
* Exibição do resultado da rodada (Vitória, Derrota ou Empate).
* Contador de pontuação (placar).

## 🛠️ Tecnologias Utilizadas
* **HTML5** (Estrutura da página)
* **CSS3** (Estilização e visual)
* **JavaScript** (Lógica do jogo)

## 🔧 Como Executar o Projeto

1. Clone este repositório para a sua máquina:
   ```bash
   git clone https://github.com
   ```

2. Navegue até a pasta do projeto e abra o arquivo `index.html` em qualquer navegador web.
